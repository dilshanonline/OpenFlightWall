Nearby flights, on your wall.

OpenFlightWall shows the planes flying over you in real time: who they are, where they're going and how far along they are. Free, keyless and open source; it runs on your own machine.

Features

Everything about the plane you just heard

Live positions from the OpenSky Network, enriched with routes, aircraft types, photos and airline logos from free community sources, and computed progress and arrival times.

"Overhead now" alerts

When a plane passes within about 3 km, a full-screen alert shows it with the airline logo on the tail, the route with cities and flags, how far along the flight is, and live altitude, speed and heading. It closes itself after a minute, or stays open if you prefer.

  • Optional browser notifications and a sound ping for new flights
  • Plane art matches the type: jumbos, wide-bodies, regional jets, turboprops, helicopters…

A live map that moves

A dark map with every plane rotated to its heading, gliding smoothly between updates and trailing its recent path. Click a plane for its photo and details and its great-circle route; click the map to move your location.

Wall mode for a TV or Raspberry Pi

Put it on a spare screen: a big clock, the nearest flights shown in turn with large aircraft art, and a ticker of everything else. It keeps the screen awake while it's showing.

Open it with the 🖥 button, or point a kiosk browser at http://localhost:5050/?wall=1, e.g. chromium --kiosk http://localhost:5050/?wall=1

Cards, a spotlight, and your phone

Every flight gets a card with its photo, airline logo, route, progress and ETA, and the closest one gets a spotlight banner. On a phone the controls fold into a menu so it works in your pocket too.

Keyless by design

No subscriptions. No API keys. No telemetry.

Every data source is free and works without an account. Everything runs on your machine; there is no OpenFlightWall server in between.

SourceProvides
OpenSky NetworkLive positions, callsign, altitude, speed, heading, squawk
hexdb.ioAircraft type from the transponder address
adsbdb.comRoute, flight number, airline, registration and aircraft photo
Kiwi.comAirline logos
OpenStreetMapMap tiles

OpenSky's anonymous limit is low. A free OpenSky account raises it a lot; add it from the ⚙ settings panel, and the credentials never leave your machine.

Quickstart

Running in a minute

Pick one. You need Python 3.11+ or Docker.

docker run -p 5050:5050 dilshanonline/openflightwall:latest
git clone https://github.com/dilshanonline/OpenFlightWall.git
cd OpenFlightWall
uv sync
uv run python app.py
git clone https://github.com/dilshanonline/OpenFlightWall.git
cd OpenFlightWall
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install flask requests python-dotenv
python app.py

Then open http://localhost:5050 and allow location access, or type your coordinates in. Full setup, OpenSky credentials and Docker options are in the README.
